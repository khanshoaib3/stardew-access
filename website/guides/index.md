
# Stardew Access Guides

Welcome! These guides help you play Stardew Valley with Stardew Access enabled. Some activities may differ from the base game, so these pages explain how to use accessibility features and play effectively.

All guides assume you have installed Stardew Valley, Stardew Access, and all required dependencies. For installation instructions, see the [setup page](/docs/setup).

Information about controls for Stardew Access and Stardew Valley can be found in [Keybindings](/docs/keybindings).
