# Stardew Access Documentation Site

This directory contains the Docusaurus-powered documentation site for Stardew Access.

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```
2. Start the local dev server:
   ```
   npm run start
   ```
3. Build the static site:
   ```
   npm run build
   ```

## Structure

- `/docs`: Guides, how-tos, and general documentation (Markdown)
- `/static/api`: API docs generated by DocFX (HTML)
- `/i18n`: Localization files

## Deployment

Deployment is handled via GitHub Actions and published to GitHub Pages.

---

For more, see the main Stardew Access repository.

If you are using GitHub pages for hosting, this command is a convenient way to build the website and push to the `gh-pages` branch.
